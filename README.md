# iOS / SideStore 中文软件源镜像

这些 JSON 是公开 AltSource 的中文显示镜像。仅翻译源名称、应用名称、简介和版本说明；Bundle ID、版本号、图标、IPA 下载地址、文件大小、哈希和最低系统版本保持原样。
